VM 1: Traditional System Application (Stock Price Change)

Updates underlying stock price. Forces external application to re-stream all 1,000,000 row-oriented tuples across the TCP/IP network from PostgreSQL on Laptop 1 and compute Black-Scholes in a single-threaded CPU loop.

Architectural Bottleneck Breakdown

  • Network Serialization: Moving $10^6$ contracts consumes $\approx 48\text{ MB}$ per revaluation over socket buffers. Over WAN/cloud links, this adds multiple seconds of latency.
  • Cache Thrashing: Relational row-oriented tuples force the CPU to load irrelevant padding and fields, causing frequent L1/L2 cache misses.
  • Instruction Stall: Scalar single-threaded loop executes Black-Scholes contract-by-contract, suffering branch mispredictions and failing to utilize 256-bit AVX2 SIMD registers.
