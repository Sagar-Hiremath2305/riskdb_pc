Academic Scaling & Architectural Evaluation

Amdahl's Law Evaluation: Problem size is fixed at 1,000,000 contracts. As thread count scales ($T = 1 \to 16$), speedup $S(T) = \frac{T_1}{T_T}$ remains near-linear due to lock-free cache-padded accumulators and $O(\log T)$ reduction.

Gustafson's Law Evaluation: Problem size scales proportionally with thread allocation ($500,000\text{ contracts/thread}$, up to $8,000,000\text{ rows}$). Execution time remains bounded while throughput scales linearly, demonstrating high sustained parallel efficiency ($\sim 95\%$).
